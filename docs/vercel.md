# PHP-сайт на Vercel

Используется `vercel-php@0.9.0` (PHP 8.5) и Node.js 22. Страницы и поиск исполняются PHP-функцией `api/index.php`; изображения, стили, скрипты, шрифты и PDF выдаются CDN по списку разрешённых путей. Файлы приложения не раздаются как статика.

## Импорт

1. Vercel → Add New → Project → `rez1dennt/domzubov` → Import.
2. Framework Preset: **Other**. Root Directory: корень репозитория.
3. Не включать собственные переопределения Build Command, Install Command и Output Directory: значения заданы в `vercel.json`.
4. В настройках проекта оставить включённым доступ к **System Environment Variables**.
5. Нажать Deploy. Для уже подключённого проекта новый push в `main` запускает публикацию автоматически.

Сайт получает адрес из `VERCEL_PROJECT_PRODUCTION_URL`, `VERCEL_URL` и `VERCEL_BRANCH_URL`. Для обычного импорта вручную задавать адрес не требуется. Свою основную ссылку можно указать через `DZ_SITE_URL=https://ваш-домен`.

Индексация по умолчанию отключена. Для готового публичного сайта она включается `DZ_ALLOW_INDEXING=1`; preview-развёртывания остаются закрытыми для индексации.

## Проверки и ограничения

- `php tests/vercel-config.php` проверяет адреса, недоверенные Host, preview, маршрутизацию и отдельные IP посетителей за прокси Vercel.
- `php -S 127.0.0.1:8174 api/index.php` запускает тот же вход PHP локально.
- PHP-runtime сообщества не поддерживает `vercel dev`; для локального просмотра используется команда выше.
- Загрузка PDF идёт через CDN, чтобы файлы больше лимита ответа функции открывались полностью.
- Счётчики частоты поиска находятся во временном каталоге отдельного экземпляра функции. Они не являются общим распределённым лимитом между всеми экземплярами Vercel.
- Отправка почты и лицензия сохраняют статус, описанный в основном README; этот перенос не изменяет интеграции клиники.

Источники: [PHP runtime](https://github.com/vercel-community/php), [системные переменные Vercel](https://vercel.com/docs/environment-variables/system-environment-variables).
