# domzubov

Сайт стоматологии «Дом Зубов» без WordPress: PHP, HTML, CSS и JavaScript.

## Запуск

Требуется PHP **8.4 или новее** с расширениями DOM и mbstring. Composer, Node.js и база данных для работы сайта не нужны.

```sh
git clone https://github.com/rez1dennt/domzubov.git
cd domzubov
php -S 127.0.0.1:8174 router.php
```

Открыть [локальный сайт](http://127.0.0.1:8174/). На Windows с PHP в `C:\php` команда запуска: `C:\php\php.exe -S 127.0.0.1:8174 router.php`.

Для Apache используются `.htaccess` и `mod_rewrite`; желательно включить `mod_headers`. Для Nginx необходимо воспроизвести ограничения доступа и маршрутизацию из `router.php`: служебные каталоги и исходные фрагменты не должны раздаваться напрямую.

## Состав

- Главная, 40 страниц услуг, врачи и их профили, отзывы, цены, контакты и информация для пациентов.
- `app/` — маршрутизация, подготовка контента, поиск, SEO и защитные проверки.
- `templates/` — общие компоненты и шаблоны.
- `content/` — данные и HTML-фрагменты приложения. Архивные записи в реестре маршрутов используются для перенаправлений; старые PDF-конверсии не входят в поставку.
- `assets/` — стили, скрипты, шрифты, изображения и опубликованные документы.
- `tests/` — проверки самостоятельной версии сайта.

Тема WordPress, резервные копии, локальная база данных, временные отчёты и неиспользуемый исходный медиаархив не включены.

## Контент и интерфейс

Врачи редактируются в `app/doctors-data.php`, материалы квалификации — в `content/doctor-certificates.json`. Общие сведения о клинике находятся в `app/company.php`. В самостоятельной версии нет WordPress и ACF.

Карточки специалистов на услугах, тематические иконки, цитаты клиники и исправления адаптива синхронизированы с версией Local. Поиск поддерживает врачей, услуги, синонимы и опечатки. История запросов сохраняется в текущей вкладке; поясняющая подпись в интерфейсе удалена.

Адрес: Москва, Симферопольский бульвар, 24, корп. 4. Часы работы: 09:00–21:00. Приём по ДМС и ОМС не ведётся.

## Публикация

Для **Vercel** уже добавлены `vercel.json`, PHP-вход `api/index.php` и runtime PHP 8.5. Импортируйте репозиторий с Framework Preset **Other**, корнем `./` и без собственных переопределений сборки. Адреса `vercel.app` определяются автоматически. Подробности — в [инструкции Vercel](docs/vercel.md).

По умолчанию индексация отключена. Для рабочего домена используются переменные окружения `DZ_SITE_URL` и `DZ_ALLOW_INDEXING=1`; подробности — в [инструкции по SEO](docs/seo-launch.md).

Запись ведёт во внешний сервис. Форма обращения подготавливает письмо в почтовой программе пользователя; серверная отправка почты не подключена. Сведения о лицензии пока содержат согласованную заглушку. Загрузка исходников в GitHub сама по себе не публикует PHP-сайт: GitHub Pages не исполняет PHP.

## Проверки

```sh
php tests/restored-structure.php
php tests/navigation-contract.php
php tests/search-test.php
php tests/doctor-profiles.php
php tests/doctor-search.php
php tests/standalone-polish.php
php tests/standalone-polish-http.php
```

Последняя проверка требует запущенного сайта на порту 8174. Браузерные сценарии Playwright находятся в `tests/restored-browser.js`, `tests/polish-browser.js` и `tests/search-dropdown.js`. Дополнительные проверки Node.js не являются зависимостью сайта.

Ограничения доступа и устройство формы описаны в [документе по безопасности](docs/security.md).
